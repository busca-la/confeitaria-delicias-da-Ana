# Delícias da Ana

Site da confeitaria, com React e Vite.

## Identidade visual
Vermelho vinho, creme e chocolate.

## Desenvolvimento
`npm install`
`npm run dev`
`npm run build`

## Pendências antes do lançamento
- Imagens de doces atuais são ilustrativas e devem ser substituídas por fotos reais autorizadas.
- Produtos, preços, telefone e endereço não foram fornecidos.
- Contato direcionado ao Instagram informado.
- É necessário testar o build e conferir o layout em navegador e celular.

Este projeto é independente do site da Tapiocaria da Fonte.
