# Delícias da Ana

Landing page da confeitaria desenvolvida em React + Vite.

## Identidade visual
- Vinho: `#771D2B`
- Creme: `#F5E8D3`
- Chocolate: `#513527`

## Desenvolvimento
```bash
npm install
npm run dev
npm run build
```

## Cardápio
- Os 16 sabores e seus valores por kg foram transcritos da arte enviada pela cliente.
- Dados organizados em `src/data/cardapio.js` para facilitar atualizações.
- Bolos feitos com chantininho, opção de massa branca ou chocolate.
- Novos sabores, cento de doces e topos especiais: preços sob consulta.
- Pagamentos: Pix, crédito, débito e dinheiro. Entrega a combinar.

## Pendências antes do lançamento
- Fotografias da hero e das categorias são **ilustrativas**: trocar por fotos reais autorizadas.
- O Instagram é o único canal de contato confirmado. Não inventar WhatsApp ou endereço.
- O item "4 leite com abacaxi" foi mantido como escrito no cardápio; confirmar a grafia com a cliente.
- Confirmar se os preços da arte continuam vigentes.
- Build, desempenho e dispositivos reais: **NÃO TESTADOS**.

Este projeto é independente da Tapiocaria da Fonte.
